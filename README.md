# Form Preview App

A simple React form preview application that updates user input in real time.

## Features

- Live form preview
- Controlled input fields using React state
- Real-time updates while typing
- Character limit for thoughts input
- Clean and responsive UI
- Beginner-friendly React project

## Inputs Included

- Name
- Thought
- Age

## How It Works

- Users enter details into the form fields
- React state stores the input values
- Preview card updates instantly with the entered data

## Tech Stack

- React
- TypeScript
- CSS
